# 🚀 Встроенный Backend в Electron

## ✅ Что изменилось

Теперь SafeWheel использует **встроенный Node.js сервер** вместо внешнего Python FastAPI:

### 🔄 Было (Python FastAPI):
- ❌ Требовал Python 3.8+
- ❌ Нужна установка зависимостей
- ❌ Отдельный процесс
- ❌ Проблемы с портами

### ✅ Стало (Node.js Express):
- ✅ **Встроен в Electron** - один исполняемый файл
- ✅ **Нет внешних зависимостей** - все включено
- ✅ **Автоматический запуск** при открытии приложения
- ✅ **Автоматическое выключение** при закрытии
- ✅ **JSON база данных** - простая и надежная

## 🏗️ Архитектура

```
SafeWheel AppImage
├── Electron (главный процесс)
├── Vue.js Frontend (встроен)
├── Express.js Backend (встроен)
└── JSON Database (data/safewheel.db)
```

## 🔧 Технические детали

### Backend Server (Node.js + Express)
- **Порт**: 8000 (автоматически меняется если занят)
- **База данных**: JSON файл (`data/safewheel.db`)
- **CORS**: Настроен для работы с Electron
- **API**: Полностью совместим с FastAPI версией

### API Endpoints
```http
GET    /api/wheels          # Получить все колеса
GET    /api/wheels/{id}     # Получить колесо по ID
POST   /api/wheels          # Создать новое колесо
PUT    /api/wheels/{id}     # Обновить колесо
DELETE /api/wheels/{id}     # Удалить колесо
```

### База данных
```json
[
  {
    "id": 1,
    "name": "Колесо 1",
    "diameter": 100.5,
    "width": 25.0,
    "material": "Резина",
    "condition": "Отличное",
    "created_at": "2024-09-09T09:30:00.000Z",
    "updated_at": "2024-09-09T09:30:00.000Z"
  }
]
```

## 🐛 Решение проблем

### Если приложение не запускается:
1. Убедитесь, что AppImage имеет права на выполнение:
   ```bash
   chmod +x dist/SafeWheel-1.0.0.AppImage
   ```

### Если данные не сохраняются:
1. Проверьте права на запись в папку приложения
2. Убедитесь, что папка `data/` создается автоматически

### Если API не отвечает:
1. Проверьте, что порт 8000 свободен
2. Приложение автоматически найдет свободный порт
