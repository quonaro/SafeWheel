# 🚗 SafeWheel - Desktop приложение для управления колесами

**SafeWheel** - это современное desktop приложение, построенное на **Electron + Vue.js + встроенный Node.js сервер**, предназначенное для управления информацией о колесах автомобилей.

## ✨ Особенности

- 🖥️ **Desktop приложение** на Electron
- 🎨 **Современный UI** с Vue.js 3 + Element Plus
- 🔧 **Встроенный API** на Express.js
- 🗄️ **JSON база данных** (встроенная)
- 🔄 **Автоматическое управление** процессами
- 📱 **Кроссплатформенность** (Windows, macOS, Linux)
- 🚀 **Один исполняемый файл** - готово к распространению
- ❌ **Нет внешних зависимостей** - все включено

```
│   └── backend-server.js  # Встроенный Express сервер

│   │   ├── services/       # API сервисы
│   │   └── main.js         # Точка входа
│   └── package.json
├── data/                   # JSON база данных
│   └── safewheel.db       # JSON файл с данными
```


## 📦 Структура проекта

### Electron (Desktop)

- **main.js** - Главный процесс Electron
- **backend-server.js** - Встроенный Express сервер

### Frontend (Vue.js)

- **Vue.js 3** - Современный фреймворк
- **Element Plus** - UI компоненты
- **Vite** - Сборщик

### Backend (Express.js)

- **Express.js** - Встроенный сервер
- **JSON база данных** - Простое хранение
- **CORS** - Настроен для Electron

## 🔧 API Endpoints

```http
GET    /api/wheels          # Получить все колеса
GET    /api/wheels/{id}     # Получить колесо по ID
POST   /api/wheels          # Создать новое колесо
PUT    /api/wheels/{id}     # Обновить колесо
DELETE /api/wheels/{id}     # Удалить колесо
```

## 🐛 Решение проблем

### Если приложение не запускается:

1. Убедитесь, что AppImage имеет права на выполнение:
   ```bash
   chmod +x dist/SafeWheel-1.0.0.AppImage
   ```

### Если данные не сохраняются:

1. Проверьте права на запись в папку приложения
2. Убедитесь, что папка `data/` создается автоматически

### Если API не отвечает:

1. Проверьте, что порт 8000 свободен
2. Приложение автоматически найдет свободный порт
