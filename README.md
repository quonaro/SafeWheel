# SafeWheel 🏆

**SafeWheel** — это десктопное приложение для управления конкурсами "Безопасное колесо" и другими соревнованиями. Приложение построено на Electron с современным веб-интерфейсом на Vue.js и использует SQLite для хранения данных.

## 🚀 Основные возможности

- **Управление конкурсами** — создание и настройка различных соревнований
- **Управление командами и участниками** — добавление команд и участников к конкурсам
- **Этапы соревнований** — создание и настройка этапов конкурса
- **Ввод результатов** — удобный интерфейс для ввода результатов по этапам
- **Таблицы результатов** — автоматический подсчет и отображение результатов
- **Экспорт в Word** — генерация отчетов в формате .docx
- **Кроссплатформенность** — работает на Windows, Linux и macOS

## 🛠 Технологический стек

### Backend

- **Electron** — фреймворк для создания десктопных приложений
- **Node.js** — серверная среда выполнения
- **SQLite (better-sqlite3)** — встроенная база данных
- **docx** — генерация Word документов

### Frontend

- **Vue.js 3** — прогрессивный JavaScript фреймворк
- **Element Plus** — UI библиотека компонентов
- **Vite** — быстрый инструмент сборки
- **Axios** — HTTP клиент для API запросов

## 📦 Установка и запуск

### Требования

- Node.js 16+
- npm или yarn

### Установка зависимостей

```bash
# Установка основных зависимостей
npm install

# Установка зависимостей фронтенда
cd frontend
npm install
cd ..
```

### Режим разработки

```bash
# Запуск в режиме разработки
npm run dev

# Или запуск только фронтенда
npm run dev:frontend
```

### Сборка для продакшена

```bash
# Сборка фронтенда
npm run build:frontend

# Сборка Electron приложения
npm run build:electron

# Сборка для Windows (portable)
npm run build:win
```

## 🎯 Основные функции

### 1. Управление конкурсами

- Создание новых конкурсов с настройкой названия, описания и эмодзи
- Просмотр списка всех конкурсов
- Выбор активного конкурса для работы

### 2. Команды и участники

- Добавление команд к конкурсу
- Регистрация участников в командах
- Управление информацией об участниках

### 3. Этапы соревнований

- Создание этапов конкурса
- Настройка параметров каждого этапа
- Управление порядком этапов

### 4. Ввод результатов

- Удобный интерфейс для ввода результатов по этапам
- Поддержка различных типов результатов
- Валидация введенных данных

### 5. Результаты и рейтинги

- Автоматический подсчет общих результатов
- Таблицы результатов по этапам
- Рейтинги участников и команд

### 6. Экспорт данных

- Генерация отчетов в формате Word (.docx)
- Экспорт результатов и рейтингов
- Настраиваемые шаблоны отчетов

## 🔧 Настройка

### Переменные окружения

- `NODE_ENV` — режим работы (development/production)
- `SAFEWHEEL_DB_DIR` — путь к директории базы данных

### Конфигурация базы данных

База данных SQLite автоматически создается при первом запуске. По умолчанию сохраняется в:

- **Windows**: `%APPDATA%/safewheel/`
- **Linux**: `~/.config/safewheel/`
- **macOS**: `~/Library/Application Support/safewheel/`

## 🚀 Сборка для разных платформ

### Windows (Unpacked)

```bash
# Используя npm скрипт
npm run build:win

# Или напрямую скрипт
./scripts/build-windows.sh

# На Windows также можно использовать batch файл
scripts\build-windows.bat
```

Создает unpacked директорию `dist/win-unpacked/` с исполняемым файлом `SafeWheel.exe`

### Windows (Portable)

```bash
npm run build:win
```

Создает portable .exe файл в папке `dist/`

### Linux (AppImage)

```bash
# Используя npm скрипт
npm run build:linux

# Или напрямую скрипт
./scripts/build-linux.sh
```

Создает AppImage файл в папке `dist/`

### macOS

```bash
npm run build
```

Создает .app пакет в папке `dist/`

## 📜 Скрипты сборки

Проект включает удобные скрипты для автоматизированной сборки:

### `scripts/build-linux.sh`

- Автоматическая сборка AppImage для Linux
- Проверка зависимостей и версий
- Цветной вывод с индикацией прогресса
- Автоматическая очистка и пересборка нативных модулей

### `scripts/build-windows.sh`

- Автоматическая сборка unpacked версии для Windows
- Поддержка как bash (Git Bash, WSL) так и обычного терминала
- Детальная информация о размерах файлов
- Проверка целостности сборки

### `scripts/build-windows.bat`

- Batch версия скрипта для Windows
- Работает в стандартной командной строке Windows
- Интерактивный режим с паузой для просмотра результатов

### Использование скриптов

```bash
# Linux AppImage
./scripts/build-linux.sh

# Windows unpacked (bash)
./scripts/build-windows.sh

# Windows unpacked (batch)
scripts\build-windows.bat

# Через npm
npm run build:linux
npm run build:win
```

## 🐛 Отладка

### Режим разработки

- Откройте DevTools с помощью `F12` или `Ctrl+Shift+I`
- Используйте `Ctrl+R` для перезагрузки
- Логи доступны в консоли Electron

### Проблемы с базой данных

- Проверьте права доступа к директории базы данных
- Убедитесь, что SQLite модуль корректно установлен
- Проверьте логи в консоли приложения

### Проблемы с better-sqlite3 в AppImage

Если AppImage не запускается с ошибкой "неверный заголовок ELF" или "NODE_MODULE_VERSION":

```bash
# Пересоберите нативные модули для Linux
npm run rebuild:linux

# Или используйте скрипт сборки, который автоматически пересобирает модули
./scripts/build-linux.sh
```
