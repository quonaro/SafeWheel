# 🚀 SafeWheel - Desktop приложение

Полнофункциональное Desktop приложение для управления колесами, построенное на **Electron + Vue.js + FastAPI + SQLite**.

## ✨ Особенности

- 🖥️ **Desktop приложение** на Electron
- 🎨 **Современный UI** с Vue.js 3 + Element Plus
- 🔧 **RESTful API** на FastAPI
- 🗄️ **База данных** SQLite с Tortoise ORM
- 🔄 **Автоматическое управление** процессами
- 📱 **Кроссплатформенность** (Windows, macOS, Linux)
- 🚀 **Готовое к распространению** приложение

## 🏗️ Архитектура

```
SafeWheel/
├── backend/                 # FastAPI + SQLite
│   ├── main.py             # API endpoints
│   ├── models.py           # Tortoise ORM модели
│   ├── process_manager.py  # Управление процессами
│   ├── install_deps.py     # Установка зависимостей
│   └── safewheel.db        # SQLite база данных
├── frontend/               # Vue.js приложение
│   ├── src/
│   │   ├── components/     # Vue компоненты
│   │   ├── services/       # API сервисы
│   │   └── main.js         # Точка входа
│   └── package.json
├── electron/               # Electron приложение
│   ├── main.js            # Главный процесс
│   └── preload.js         # Preload скрипт
└── package.json           # Основные зависимости
```

## 🚀 Быстрый старт

### Установка зависимостей

```bash
# Установка основных зависимостей
npm install

# Установка зависимостей фронтенда
cd frontend && npm install && cd ..

# Установка зависимостей бэкенда
cd backend && pip install -r requirements.txt && cd ..
```

### Запуск приложения

#### Режим разработки:

```bash
# Простой запуск (рекомендуется)
npm run dev

# Или запуск вручную
NODE_ENV=development electron .
```

#### Продакшен режим:

```bash
# Сборка приложения
./build-app.sh

# Запуск собранного приложения
npm start
```

## 🎯 Функциональность

### ✅ Управление колесами

- ➕ **Добавление** новых колес с полной информацией
- ✏️ **Редактирование** существующих записей
- 🗑️ **Удаление** колес с подтверждением
- 📊 **Просмотр** всех колес в удобной таблице

### ✅ Поля данных

- **Название** колеса
- **Диаметр** (в мм)
- **Ширина** (в мм)
- **Материал** (Резина, Пластик, Металл, Композит)
- **Состояние** (Отличное, Хорошее, Удовлетворительное, Плохое)

### ✅ База данных

- **SQLite** для локального хранения
- **Tortoise ORM** для работы с данными
- **Автоматическое создание** схем таблиц
- **Персистентность** данных между сессиями

## 🔧 Технические детали

### Backend (FastAPI)

- **Порт**: 8000
- **API документация**: http://localhost:8000/docs
- **База данных**: SQLite (`backend/safewheel.db`)
- **ORM**: Tortoise ORM
- **CORS**: Настроен для работы с Electron
- **Автозапуск**: Встроен в Electron приложение

### Frontend (Vue.js)

- **Порт**: 3000 (разработка) / встроен (продакшен)
- **UI библиотека**: Element Plus
- **Сборщик**: Vite
- **Горячая перезагрузка**: Включена в разработке

### Desktop (Electron)

- **Управление процессами**: Автоматическое
- **Безопасность**: Content Security Policy
- **DevTools**: Доступны в режиме разработки
- **Меню**: Скрыто для чистого интерфейса

## 🛠️ Разработка

### Структура API

```http
GET    /api/wheels          # Получить все колеса
GET    /api/wheels/{id}     # Получить колесо по ID
POST   /api/wheels          # Создать новое колесо
PUT    /api/wheels/{id}     # Обновить колесо
DELETE /api/wheels/{id}     # Удалить колесо
```

### Управление процессами

Electron автоматически управляет всеми процессами:

- **Запуск**: При старте Electron запускается бэкенд (и фронтенд в режиме разработки)
- **Остановка**: При закрытии Electron все процессы завершаются
- **Мониторинг**: Автоматическое отслеживание состояния процессов

### База данных

```python
# Модель колеса
class Wheel(Model):
    id = fields.IntField(pk=True)
    name = fields.CharField(max_length=255)
    diameter = fields.FloatField()
    width = fields.FloatField()
    material = fields.CharField(max_length=100)
    condition = fields.CharField(max_length=100)
    created_at = fields.DatetimeField(auto_now_add=True)
    updated_at = fields.DatetimeField(auto_now=True)
```
