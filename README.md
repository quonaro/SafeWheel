# Безопасное колесо

Десктопное приложение для управления соревнованиями «Безопасное колесо» — детскими конкурсами по правилам дорожного движения и велосипедной безопасности.

## Возможности

- **Соревнования** — создание, редактирование и удаление конкурсов с настройками (макс. участников в команде, описание)
- **Команды и участники** — управление составами команд: ФИО, пол, дата рождения, возраст
- **Этапы** — настройка этапов соревнования с порядком проведения
- **Ввод результатов** — время прохождения, штрафные очки, количество правильных ответов по каждому этапу
- **Турнирная таблица** — автоматический расчёт мест:
  - Общий зачёт (сумма мест, количество 1-х/2-х/3-х мест)
  - Результаты по этапам
  - Индивидуальный зачёт (раздельно среди мальчиков и девочек)
- **Экспорт в Word (.docx)** — общие результаты, результаты по этапам, сводный отчёт по всем соревнованиям
- **Тёмная и светлая тема** интерфейса
- **Кроссплатформенность** — Windows и Linux

## Технологии

| Слой        | Технология                                          |
| ----------- | --------------------------------------------------- |
| Backend     | Go 1.25, Wails v2.15                                |
| Frontend    | Vue 3, TypeScript, Vite 7                           |
| UI          | Tailwind CSS v4, shadcn-vue (reka-ui), Tabler Icons |
| База данных | SQLite (modernc.org/sqlite — чистый Go, без CGO)    |

## Требования

- **Go** 1.25+
- **Node.js** 18+ и npm
- **Wails CLI** v2.15: `go install github.com/wailsapp/wails/v2/cmd/wails@latest`
- **Linux:** `webkit2gtk-4.1`, `libgtk-3-dev`, `pkg-config`
- **Windows:** WebView2 (устанавливается автоматически на Windows 10/11)

## Запуск

### Разработка

```bash
wails dev -tags webkit2_41
```

или через lota:

```bash
lota dev
```

База данных создаётся рядом с исполняемым файлом. Для dev-режима используется `APP_DIR=./` (настраивается в `lota.yml`).

### Сборка

```bash
# Windows (amd64) + NSIS установщик
wails build -tags webkit2_41 -ldflags "-s -w" -trimpath -platform windows/amd64 -nsis

# Linux (amd64)
wails build -tags webkit2_41 -ldflags "-s -w" -trimpath -platform linux/amd64
```

или через lota:

```bash
lota build.all
```

Готовые бинарники попадают в `build/bin/`.

## Расположение базы данных

По умолчанию `safewheel.db` создаётся в директории рядом с исполняемым файлом. Переопределить можно переменной окружения `APP_DIR`:

```bash
APP_DIR=/path/to/dir ./safe-wheel
```

На Windows установщик так же создаёт `safewheel.db` рядом с исполняемым файлом в `%LOCALAPPDATA%\Programs\SafeWheel`.
