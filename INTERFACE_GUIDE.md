# 🎨 Руководство по интерфейсу SafeWheel

## ✨ Особенности интерфейса

### 🖥️ Чистый интерфейс

- **Меню браузера скрыто** для более чистого вида
- **DevTools не открываются автоматически**
- **Полноэкранный режим** для максимального использования пространства

### ⌨️ Горячие клавиши

#### В режиме разработки:

- **F12** - Открыть/закрыть DevTools
- **Ctrl+Shift+I** - Открыть/закрыть DevTools
- **Ctrl+R** - Перезагрузить приложение
- **Ctrl+Shift+R** - Принудительная перезагрузка (игнорируя кэш)
- **Alt** - Показать/скрыть меню приложения

#### Общие:

- **Ctrl+C** - Копировать
- **Ctrl+V** - Вставить

### 🖱️ Контекстное меню (правый клик)

При правом клике на любом месте приложения появляется контекстное меню с опциями:

- **Копировать** (Ctrl+C)
- **Вставить** (Ctrl+V)
- **Инструменты разработчика** (F12) - только в режиме разработки
- **Перезагрузить** (Ctrl+R) - только в режиме разработки
- **Показать меню приложения** (Alt)

### 🔧 Режимы работы

#### Режим разработки (`NODE_ENV=development`):

- Автоматический запуск бэкенда и фронтенда
- Доступ к DevTools через горячие клавиши
- Горячая перезагрузка при изменениях
- Дополнительные опции в контекстном меню

#### Продакшен режим:

- Чистый интерфейс без DevTools
- Только основные функции
- Минимальное контекстное меню

### 🎯 Управление приложением

#### Запуск:

```bash
# Режим разработки
npm run dev

# Продакшен режим
npm start
```

#### Закрытие:

- **Закрытие окна** - автоматически завершает все процессы
- **Ctrl+C** в терминале - корректное завершение
- **Alt+F4** (Windows) / **Cmd+Q** (macOS) - закрытие приложения

### 🔄 Автоматическое управление процессами

Electron автоматически управляет всеми компонентами:

1. **При запуске**:

   - Запускается Electron
   - Автоматически запускается бэкенд (FastAPI)
   - Автоматически запускается фронтенд (Vue.js)

2. **При закрытии**:
   - Все процессы корректно завершаются
   - База данных сохраняется
   - Нет "висящих" процессов

### 🎨 Внешний вид

- **Современный дизайн** с Element Plus
- **Адаптивная верстка** под разные размеры окна
- **Темная/светлая тема** (зависит от системы)
- **Плавные анимации** и переходы

### 🛠️ Отладка

Для отладки используйте:

- **F12** - открыть DevTools
- **Ctrl+R** - перезагрузить приложение
- **Ctrl+Shift+R** - принудительная перезагрузка

### 📱 Кроссплатформенность

Приложение работает на:

- **Windows** - с поддержкой Windows-специфичных горячих клавиш
- **macOS** - с поддержкой Cmd вместо Ctrl
- **Linux** - с полной поддержкой всех функций
