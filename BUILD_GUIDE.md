## 🚀 Быстрая сборка

### Простая сборка (рекомендуется):

```bash
./simple-build.sh
```

### Ручная сборка:

```bash
# 1. Сборка фронтенда
cd frontend
npm install
npm run build
cd ..

# 2. Сборка Electron
npm run build:electron
```

После сборки в папке `dist/` будет:

- **SafeWheel-1.0.0.AppImage** - готовое приложение для Linux

## 🎯 Особенности собранного приложения

### ✅ Автоматическое управление процессами:

- **При запуске**: Автоматически запускается бэкенд FastAPI
- **При закрытии**: Автоматически выключается бэкенд
- **База данных**: SQLite создается автоматически

### ✅ Встроенные компоненты:

- **Frontend**: Собранный Vue.js приложение
- **Backend**: Python скрипты для FastAPI
- **Database**: SQLite база данных

### ✅ Чистый интерфейс:

- **Меню браузера**: Скрыто
- **DevTools**: Доступны по F12 (только в режиме разработки)
- **Контекстное меню**: Правый клик для основных функций

## 🔧 Требования для сборки

- **Node.js** 16+
- **Python** 3.8+
- **npm** или **yarn**

## 🔧 Требования для запуска

- **Python** 3.8+ (для бэкенда)
- **Linux** (для AppImage)

## 🚀 Запуск собранного приложения

```bash
# Запуск AppImage
./dist/SafeWheel-1.0.0.AppImage

# Или через файловый менеджер
# Двойной клик на SafeWheel-1.0.0.AppImage
```

## 🐛 Решение проблем

### Если приложение не запускается:

1. Убедитесь, что Python 3.8+ установлен
2. Установите зависимости: `pip install -r backend/requirements.txt`
3. Проверьте права на выполнение: `chmod +x dist/SafeWheel-1.0.0.AppImage`

### Если бэкенд не запускается:

1. Проверьте, что Python доступен в PATH
2. Установите зависимости вручную
3. Запустите в режиме разработки для отладки
