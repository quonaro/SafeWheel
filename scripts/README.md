# Скрипты сборки SafeWheel

Этот каталог содержит скрипты для автоматизированной сборки приложения SafeWheel для разных платформ.

## 📜 Доступные скрипты

### `build-linux.sh`

Скрипт для сборки AppImage версии для Linux.

**Особенности:**

- ✅ Автоматическая проверка Node.js и npm
- ✅ Цветной вывод с индикацией прогресса
- ✅ Автоматическая очистка и пересборка нативных модулей
- ✅ Проверка целостности сборки
- ✅ Создание исполняемого AppImage файла

**Результат:** `dist/SafeWheel-1.0.0.AppImage` (размер ~181MB)

### `build-windows.sh`

Скрипт для сборки unpacked версии для Windows.

**Особенности:**

- ✅ Поддержка bash (Git Bash, WSL)
- ✅ Детальная информация о размерах файлов
- ✅ Проверка наличия исполняемого файла
- ✅ Список содержимого сборки

**Результат:** `dist/win-unpacked/` директория с `SafeWheel.exe` (размер ~794MB)

### `build-windows.bat`

Batch версия скрипта для Windows.

**Особенности:**

- ✅ Работает в стандартной командной строке Windows
- ✅ Интерактивный режим с паузой
- ✅ Проверка зависимостей

**Результат:** `dist/win-unpacked/` директория с `SafeWheel.exe`

## 🚀 Использование

### Через npm скрипты (рекомендуется)

```bash
# Linux AppImage
npm run build:linux:appimage

# Windows unpacked
npm run build:win:unpacked
```

### Напрямую

```bash
# Linux
./scripts/build-linux.sh

# Windows (bash)
./scripts/build-windows.sh

# Windows (batch)
scripts\build-windows.bat
```

## 📋 Требования

- **Node.js** 16+
- **npm** (обычно поставляется с Node.js)
- **Git** (для клонирования репозитория)

## 🔧 Что делают скрипты

1. **Проверка зависимостей** - проверяют наличие и версии Node.js/npm
2. **Очистка** - удаляют предыдущие сборки
3. **Установка зависимостей** - устанавливают npm пакеты если нужно
4. **Сборка фронтенда** - компилируют Vue.js приложение
5. **Копирование зависимостей** - подготавливают нативные модули
6. **Пересборка нативных модулей** - пересобирают better-sqlite3 для целевой платформы
7. **Сборка Electron** - создают финальную сборку
8. **Проверка результата** - проверяют успешность сборки

## ⚠️ Важные замечания

- Скрипты автоматически очищают предыдущие сборки
- Для Windows сборки требуется пересборка нативных модулей
- AppImage файл автоматически делается исполняемым
- Все скрипты останавливаются при ошибках (`set -e`)

## 🐛 Решение проблем

### Ошибка "Node.js не найден"

Установите Node.js 16+ с официального сайта: https://nodejs.org/

### Ошибка "npm не найден"

npm обычно поставляется с Node.js. Переустановите Node.js.

### Ошибка сборки нативных модулей

```bash
# Очистите кэш npm
npm cache clean --force

# Переустановите зависимости
rm -rf node_modules frontend/node_modules
npm install
cd frontend && npm install && cd ..
```

### Ошибка прав доступа (Linux)

```bash
# Сделайте скрипты исполняемыми
chmod +x scripts/*.sh
```
